# Human Test Checklist: every pane close through the after-action rule, and the Esc reminder

**Target version:** 0.4.18
**Ships with commit:** feat(band): the after-action rule decides every close; an Esc reminder after a band action (v0.4.18)
**Companion automated tests:** `claude plugin test plugin` (11, of which `plugin/tests/after-action.test.ts` 3); `node --test tests/core/*.test.ts` (130, `after-action.test.ts` among them)

## What this is

The live looks for #24 and #29's close policy: what a person sees when they start typing after a band action, and that panes still close as before.

## Planning lineage

**Public (in this repo)**: `docs/engine-quirks.md`, "A plugin can't hand the keyboard back to the input box"; `CHANGELOG.md` [0.4.18]; issues #24, #29, #18.

**Project-private** (not in public git history, for project maintainers): `2026-10-12__02-27-47__goal__first-foundations-through-the-split.md` (slice 2).

## Prerequisites

Claude Code started from a shell with the plugin loaded from this working tree (`claude --plugin-dir <repo>/plugin`), a conversation with a few marks set, and "Keyboard after an action" at its default (`input`) in `/config`.

---

## High-Value Verification (~5 minutes)

### HV.1 — The reminder after `o`

- [ ] **Steps:** `Ctrl+] o` (back), then type `hello`.
- [ ] **Expected:** a toast says to press `Esc` to type in the input box; nothing collects in the band's field; the reminder shows once, not per letter (later letters show the usual key hint). `Esc`, then typing, goes into the input box.
- [ ] **Why this matters:** the person's next words used to vanish into the band (#24).

### HV.2 — Not when nothing happened first

- [ ] **Steps:** `Esc` to the input box; `Ctrl+] h`.
- [ ] **Expected:** the usual key hint, no Esc reminder.

### HV.3 — Not when the keyboard should stay in the band

- [ ] **Steps:** set "Keyboard after an action" to `band`; `Ctrl+] o`, type `h`.
- [ ] **Expected:** the usual key hint, no reminder. Set it back to `input`.

### HV.4 — Panes close as before

- [ ] **Steps:** `Ctrl+] '` then a letter (jump); `Ctrl+] m` then a letter (mark); in the jump pane press the reading row; `Ctrl+] p`, then `go` with no number typed.
- [ ] **Expected:** each closes its pane as in 0.4.17; the mark scrolls back to where you were.
