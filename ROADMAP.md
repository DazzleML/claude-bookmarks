# Roadmap

The living roadmap is **[issue #1](https://github.com/DazzleML/claude-bookmarks/issues/1)**. This file is a summary.

North star: [anthropics/claude-code#94786](https://github.com/anthropics/claude-code/issues/94786), conversation linking and anchoring to specific messages.

| Pillar | What it means | Status |
|---|---|---|
| 1. Navigate | Highlighted marks with vim chords; one-chord reading position | Proven in the proof of concept |
| 2. Aliases | A memorable name alongside each letter | Planned (v0.x) |
| 3. Rich metadata | Notes, timestamps, multiple links and resources per mark | Planned (v0.x) |
| 4. Attachments | Open a mark's URLs, files and vault notes through configurable handlers | Planned (v0.x) |

**1.0** = all four pillars in reasonable working order, with most of their sub-features.
