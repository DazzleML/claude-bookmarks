# Human Test Checklist: one palette, by role, on dark and light themes

**Target version:** 0.4.19
**Ships with commit:** feat(palette): every colour by role, readable on dark and light themes (v0.4.19)
**Companion automated tests:** `node --test tests/core/palette.test.ts` (8, including "register.tsx draws no colour of its own"); `claude plugin test plugin` (14, `plugin/tests/palette.test.ts` 3)

## What this is

How the plugin looks now that every colour comes from one palette by role (#27): the colours themselves, on a real terminal, on a dark and on a light theme, and an override set in `/config`.

**Public (in this repo)**: `README.md` "Configuration" (the "Colour overrides" setting); `docs/usage.md` "Settings"; `CHANGELOG.md` [0.4.19]; issue #27.

## Prerequisites

Claude Code started from a shell with the plugin loaded from this working tree, a conversation with marks `a` and `b` (one on a prompt, one on a reply), a pinned prompt, and the `theme` row of `/config` noted so it can be restored.

## High-Value Verification (~5 minutes)

### HV.1 — Dark theme: nothing looks different from 0.4.18

- [ ] **Steps:** with a dark theme, look at a marked prompt and a marked reply; `Ctrl+] p` (the prompts list, with the pin star and the yellow "nearest" row); `Ctrl+] m` (the mark pane: taken letters, free letters); `Ctrl+] b` (the bookmarks list).
- [ ] **Expected:** the mark band and its bold letter and words, the yellow nearest row, the pin star, the dim legends and buttons look as before; the prompts list legend now shows `#N` drawn in the nearest-row colour instead of the word "yellow"; taken letters in the mark pane use the theme's inactive colour instead of a grey-red.
- [ ] **Why this matters:** the palette is meant to change nothing on the default theme except naming its colours by role.

### HV.2 — Light theme: everything reads

- [ ] **Steps:** switch `/config`'s theme to a light one; repeat HV.1's looks.
- [ ] **Expected:** the mark band is a pale blue (not the dark navy), and every role is readable on the light background.
- [ ] **Why this matters:** the dark-only colours were the reason for #27.

### HV.3 — An override

- [ ] **Steps:** in `/config`, set "Colour overrides" to `{"here": {"color": "cyan"}, "markBand": {"backgroundColor": "#203040"}}`; open the prompts list; look at a marked line. Then set it to `not json`.
- [ ] **Expected:** the nearest row is cyan and the mark band the given colour; with `not json`, the defaults return and nothing breaks.
