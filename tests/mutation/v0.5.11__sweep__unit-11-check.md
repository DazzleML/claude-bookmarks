## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing. **A clean sweep is evidence about the mutations tried, not proof of suite completeness.** Nothing here runs `/bm-check` against a real data root with real run folders; that is a line in unit 12's checklist. The red-green audit of the seven new tests (7 anchors / 0 guards, `scratchpad/redgreen/audit11.py`) is the separate check that those tests are attached to the change.
